# 🔥 Roadmap Roast

Paste in your roadmap. Get it taken apart by fifteen years of accumulated product
writing, with receipts.

Better than asking a colleague, in one specific way: it can't be polite to you, and
every criticism comes with a link to someone who argued it first.

## Paste this

```
I'm going to paste a roadmap. Use the Mind the Product MCP to critique it.

Do this:
1. Read it, and tell me back what you think this team is actually betting on. If
   that's unclear, say so — that's finding number one.
2. Search Mind the Product for writing relevant to what I'm doing, and use it to
   find the three or four biggest problems. Cite each one.
3. For each problem: what's wrong, why it matters, and the smallest change that
   would fix it.
4. Tell me what's *good* about it too, and mean it — don't manufacture praise.
5. Finish with the one question a sceptical exec will ask that this roadmap
   currently can't answer.

Be direct. I'd rather hear it now.

Here's the roadmap:
[paste yours here]
```

## Make it yours

- **PRD Roast** — same prompt, paste a spec instead.
- **Strategy Roast** — paste a strategy doc; ask it to test whether it's a strategy
  or a list of wishes.
- **Pre-mortem** — "It's a year later and this roadmap failed. Using Mind the
  Product, write the post-mortem."
- **Gentler** — "Frame everything as a question rather than a criticism." Useful if
  you're going to share the output with the team.
