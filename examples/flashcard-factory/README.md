# 🃏 Flashcard Factory

The one that actually builds you something. Your AI reads real Mind the Product
articles, pulls out the frameworks worth knowing, and writes you a working flashcards
app as a single HTML file. Open it in a browser, keep it forever, no internet needed
after that.

Good first project if you've never had an AI build you an app before — the MCP does
the hard part, which is knowing what should be on the cards.

## Paste this

```
Build me a flashcards app, using the Mind the Product MCP for the content.

Step 1 — get the content:
- Search Mind the Product for the product frameworks and concepts worth knowing.
- Cover discovery, prioritisation, metrics, strategy, and stakeholder management.
- For each one, read the full article so the definition is accurate, not vague.
- Aim for 30 cards. Front: the concept. Back: a clear explanation in your own words,
  when to use it, and the article URL.

Step 2 — build it:
- One self-contained HTML file. No build step, no dependencies, no CDN links.
- Click or press space to flip. Arrow keys to move.
- Track which ones I get right, and show the ones I miss more often.
- Works on a phone.
- Make it look calm and readable — this is for studying, not a demo.

Save it as flashcards.html and tell me how to open it.
```

## Make it yours

- **Interview prep** — "Only concepts that come up in PM interviews, and add a
  'how would you answer this out loud' side."
- **Team onboarding** — "Aim it at someone in their first PM job."
- **Spaced repetition** — "Add Leitner boxes and save progress to localStorage."
- **Print version** — "Also give me a printable PDF layout, 8 cards a page."
